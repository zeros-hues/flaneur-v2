# Artifact, Encounter and captured-source inspection

Local implementation, 2026-10-13. `/artifact/[id]`, `/encounter/[id]` and `/snapshot/[id]` provide owner-protected, read-only inspection. Static generic metadata exposes no private names; page authorization precedes ID validation and database reads. Street links each object and its captured evidence/encounter. Walk Artifact stops now open their internal inspection page after their explicit opened event is acknowledged.

Artifact inspection preserves stored text and paginates it in exact 10,000-code-point sections. It shows linked captures, recorded Encounter associations and paged observation/evidence/review history. Existing text and legacy Person associations are labelled without treating them as verified source text or authorship. Encounter inspection retains exact explicit context, recorded timestamps and source metadata; JSON is rendered from PostgreSQL text to preserve large numbers. Object link relations remain recorded associations, not inferred authorship. Archived canonical objects remain inspectable as history; aliased objects are excluded without guessed redirects.

Captured-source inspection displays exact captured markup as escaped plain text, never an iframe or executable HTML. Original gzip bytes can be downloaded through owner-authenticated `/api/snapshot/[id]/download`, with private/no-store/nosniff attachment headers and a fixed UUID filename. Stored parser/adapter/coverage/hash metadata is distinguished from proof of complete coverage or historical hash/clock verification. Known Artifact/Encounter links preserve the return path.

Immutable normalized representations are separately selectable by recorded normalizer version. The selected representation must belong to the requested snapshot; foreign/missing representation IDs fail. Source quotes reuse Unicode-code-point verification against matching stored representations. Quote integrity is distinguished from semantic support; supports/contradicts roles and truth layers remain visible. User verification means authorship, not external factual verification.

All readers use checked repeatable-read read-only transactions and bounded queries. Original bytes are untouched. Source decoding is bounded at 2 MiB of decompressed UTF-8; the buffered original-byte download is bounded at 4 MiB compressed. Malformed gzip/UTF-8 or excessive expansion produces an explicit unavailable viewer state, not truncated success. Large original bytes remain stored, with download unavailable when its limit is exceeded. Large-corpus delivery remains a separate gap. Artifact/source text pagination preserves original spacing and Unicode; PostgreSQL substring arguments are explicitly integer-cast to avoid its regex overload.

Snapshots/encounters/observations use independent UUID cursor pages of 20 with explicit next links. Encounter links cap at 200, context at 128,000 UTF-8 bytes and representation versions at 20; exceeding those bounds fails explicitly. UUID pagination provides stable traversal rather than implying chronological ordering. No backfill is performed when a historical association or capture is missing. Original inspection is read-only; mutation controls for these surfaces remain subsequent work.
